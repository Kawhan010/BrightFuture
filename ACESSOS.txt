COMO ENTRAR
-----------
Abra login.html usando a extensão Live Server do VS Code.
Ou abra index.html: sem sessão ativa, o sistema abre o login automaticamente.
Os usuários são predefinidos para o trabalho de faculdade; não há registro público.

IMPORTANTE
----------
Este login é feito apenas no navegador, com credenciais no código.
Permissões são demonstrativas e NÃO protegem dados reais nem substituem um servidor seguro.
Não use informações verdadeiras de crianças, familiares ou professores.
Todos os usuários compartilham os dados salvos no MESMO navegador, pelo localStorage.
